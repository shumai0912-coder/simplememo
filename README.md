# ThinkSpace - 空間思考ノート

研究者、エンジニア、学生のための、図で考えるための無限キャンバス型ノートアプリ。

## 機能 (MVP)
- **無限キャンバス**: 制限のない広大な空間での思考。
- **手書き機能**: スムーズな手書き入力とインク平滑化。
- **図形描画**: 矩形、円、矢印、線などの基本図形。
- **コネクション**: 要素同士を線でつなぎ、論理構造を可視化。
- **永続化**: ブラウザの IndexedDB を使用した自動保存。

## 使用技術
- React / TypeScript
- Vite
- [tldraw](https://tldraw.dev/) (キャンバスエンジン)
- Lucide React (アイコン)
- Vanilla CSS (プレミアム・グラスモフィズムデザイン)

## 始め方

1. **依存関係のインストール**:
   ```bash
   npm install
   ```

2. **開発サーバーの起動**:
   ```bash
   npm run dev
   ```

3. **ビルド**:
   ```bash
   npm run build
   ```
